# 📖 Games for Kindle

Колекція ігор, оптимізованих для браузера Amazon Kindle (Experimental Browser).

## Як грати
1. Відкрийте браузер на Kindle (Menu → Experimental Browser)
2. Перейдіть за адресою сайту
3. Використовуйте **хрестовину** для навігації
4. Натискайте **центральну кнопку** для вибору

## Особливості
- ✅ Тільки HTML + CSS (без JavaScript)
- ✅ Великі клікабельні зони
- ✅ Високий контраст для E-Ink
- ✅ Серифні шрифти для зручного читання
