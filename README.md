# Games for Kindle / Ігри для Kindle

A collection of browser-based games optimized for Amazon Kindle devices.
Колекція ігор для браузера Amazon Kindle.

---

## 🇬🇧 English

### How to play
1. Open the browser on your Kindle (Menu → Experimental Browser)
2. Navigate to the site URL
3. Select your device version (Old/New Kindle)
4. Choose a game and enjoy!

### Features
- ✅ Pure HTML + CSS (no JavaScript required for classic version)
- ✅ Large clickable areas for easy navigation
- ✅ High contrast for E-Ink displays
- ✅ Serif fonts for comfortable reading
- ✅ Multi-language support (EN, UK, DE, PL)

### Games
- 📜 **Classic version** (for Kindle with buttons):
  - Lighthouse Mystery - text quest
  - Word Game
  - Quiz
  - Dungeon Adventure

- 📱 **Modern version** (for touch Kindle):
  - Sudoku
  - Hangman
  - Minesweeper
  - Tic-Tac-Toe
  - Memory
  - Word Guess
  - Quiz
  - Chess
  - 2048
  - Snake
  - Puzzle 15
  - Reaction Test

### Supported Languages
- English
- Ukrainian (Українська)
- German (Deutsch)
- Polish (Polski)

## 🇵🇱 Polski

### Jak grać
1. Otwórz przeglądarkę na Kindle (Menu → Przeglądarka eksperymentalna)
2. Przejdź do adresu URL strony
3. Wybierz wersję urządzenia (Stary/Nowy Kindle)
4. Wybierz grę i baw się dobrze!

### Funkcje
- ✅ Tylko HTML + CSS (bez JavaScript dla wersji klasycznej)
- ✅ Duże klikalne obszary dla łatwej nawigacji
- ✅ Wysoki kontrast dla wyświetlaczy E-Ink
- ✅ Czcionki szeryfowe dla wygodnego czytania
- ✅ Wsparcie dla wielu języków (EN, UK, DE, PL)
