About Kindle Games

This project was created for Kindle enthusiasts who want to enjoy games on their e-ink devices during breaks from reading.

What is this?

Kindle Games is a collection of browser-based games optimized for Amazon Kindle devices. All games work directly in the Kindle's experimental browser - no installation required!

Supported Devices

  • Old Kindle (with physical buttons): Text quests, quizzes, and puzzle games that work without JavaScript
  • New Kindle (touchscreen): All games including Sudoku, Chess, 2048, Snake, Tetris and more
  • Kindle Paperwhite, Kindle Oasis, Kindle Scribe - all supported!

How to Play

For New Kindle (touchscreen):
  1. Open the browser on your Kindle
  2. Navigate to this website
  3. Select "New Kindle"
  4. Choose a game and enjoy!
For Old Kindle (with buttons):
  1. Open the browser (Menu → Experimental Browser)
  2. Navigate to this website
  3. Select "Old Kindle"
  4. Use the 5-way controller to navigate
  5. Press center button to select

Features

  • ✅ 15+ games across different genres

Games List

For New Kindle:

  • Sudoku, Minesweeper, Puzzle 15, 2048, Tetris
  • Snake, Reaction Test, Tic-Tac-Toe, Memory
  • Hangman, Word Guess, Quiz
  • Chess
  • Text Quests: Lighthouse Mystery, Space Station, Castle of Shadows, Detective Case #47

For Old Kindle:

  • Text Quests (all 4 stories with 15-20 scenes each)
  • World Capitals Quiz
  • Maze Adventure
  • Book of Riddles (10 riddles)
